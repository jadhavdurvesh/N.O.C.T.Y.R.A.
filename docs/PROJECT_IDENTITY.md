# Project Identity

## NOCTYRA
**Neural Obfuscation & Cryptographic Transmission Yielding Resilient Archives**

The expansion is a project identity and branding phrase. It does not imply that the implementation uses neural networks.

## CONSTELLATION
The multi-carrier transport protocol for distributing and reconstructing an encrypted NCT archive from validated carrier fragments.
