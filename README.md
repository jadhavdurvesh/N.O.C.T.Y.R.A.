# N.O.C.T.Y.R.A.

**Neural Obfuscation & Cryptographic Transmission Yielding Resilient Archives**

Private cross-platform project for authenticated encrypted archives, image-carrier research, and resilient multi-carrier transport through CONSTELLATION.

> Encryption protects the content. Image-carrier techniques do not guarantee that embedded data is undetectable.

See `docs/` for architecture, threat model, format drafts, and roadmap. This is an early development project and is not ready for protecting real sensitive data.
